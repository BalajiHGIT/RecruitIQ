# RecruitIQ - Project Overview

## Project Name
RecruitIQ - Recruitment and Placement Management System

## Description
RecruitIQ is a web-based recruitment and placement management system developed using Python, Flask and MySQL.

## Main Modules
- Dashboard
- Candidate Management
- Company Management
- Job Management
- Application Management
- Interview Management
- Offer Management
- Placement Management
- Reports
- AI Resume Screening (keyword-based matching)

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
