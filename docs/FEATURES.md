# RecruitIQ - Features

## Main Features
- Admin Login and Authentication
- Dashboard Overview
- Candidate Management
- Company Management
- Job Management
- Application Tracking
- Candidate Eligibility Checking
- Interview Scheduling and Feedback
- Offer Management
- Placement Tracking
- Recruitment Reports
- Keyword-Based Resume Screening

## Technology Stack
- Backend: Python and Flask
- Database: MySQL
- Frontend: HTML, CSS and JavaScript
