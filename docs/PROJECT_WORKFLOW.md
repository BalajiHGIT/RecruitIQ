# RecruitIQ - Project Workflow

## Application Workflow

1. Admin opens the RecruitIQ application.
2. Admin logs in to the system.
3. Candidate information is managed.
4. Company details are added and maintained.
5. Job openings are created.
6. Candidate eligibility is checked against job requirements.
7. Eligible candidates can be processed through applications.
8. Applications are shortlisted.
9. Interviews are scheduled and feedback is recorded.
10. Selected candidates receive offers.
11. Offer acceptance and placement details are managed.
12. Reports help monitor recruitment and placement activities.

## Resume Screening
RecruitIQ uses keyword-based resume screening to compare resume skills with job requirements.

## Main Technologies
Python, Flask, MySQL, HTML, CSS and JavaScript.
