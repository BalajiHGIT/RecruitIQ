# RecruitIQ - Installation Guide

## Requirements
- Python 3.x
- MySQL Server 8.0
- Visual Studio Code
- Web Browser

## Setup Steps
1. Clone or download the RecruitIQ repository.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install the required packages using requirements.txt.
5. Configure the database settings in the environment file.
6. Create the recruitment_placement database.
7. Import the database/schema.sql file into MySQL.
8. Start the application using python app.py.
9. Open the application in a web browser.
